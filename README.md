# 🎵 Spot2About

**Your music. Your WhatsApp About. Automatically.**

Spot2About is a free browser extension that automatically displays the song you're listening to on Spotify in your WhatsApp About.

No more manually changing your About every time your favorite song changes!

## ✨ Features

- 🎵 Automatically sync Spotify songs to WhatsApp About
- 🔄 Update when the song changes
- 👀 Show a custom message after 30 seconds without music
- 🎨 Modern dark-themed interface
- ⚙️ Enable or disable automatic syncing
- ✂️ Automatically shorten messages to fit the 50-character limit
- 🛡️ Avoid unnecessary duplicate updates

## 🌐 Browser compatibility

Designed for Chromium-based browsers:

- Google Chrome
- Microsoft Edge
- Brave
- Opera / Opera GX
- Vivaldi

**Note:** Cross-browser testing is ongoing.

## 🚀 Installation

1. Download the latest extension files.
2. Extract them into a folder.
3. Open your browser's extension management page.
4. Enable Developer mode.
5. Select **Load unpacked** and choose the extension folder.
6. Open Spotify Web Player and WhatsApp Web in the same browser.
